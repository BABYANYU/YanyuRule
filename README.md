# YanyuRule

面向多种代理客户端的规则库，提供可订阅、可筛选的规则集与本地过滤模块。

## 支持客户端

Surge · Mihomo · Loon · Quantumult X · Shadowrocket · Egern · sing-box · Surfboard

## 开始使用

1. 打开 [YanyuRule 规则库](https://rule.fakeyou.eu.org/)。
2. 选择客户端和规则，复制页面生成的链接；规则详情还提供可用文件的复制链接与下载入口。
3. 将链接按客户端支持的订阅或规则集方式添加；具体入口和格式以客户端版本说明为准。
4. 规则有更新时，使用客户端自己的订阅更新功能。

Surge 使用 INI，Mihomo 使用 YAML，二者不能互换；Mihomo 的 YAML、TEXT 按规则行为选择，MRS 为二进制格式。sing-box、Surfboard 等客户端使用页面提供的兼容文件。

## 页面筛选与排序

- 选择侧栏中的客户端标签；移动端可用客户端下拉框。首页默认 Surge。
- 搜索框可匹配规则名称、中文名称或说明；客户端与规则选择会反映在页面地址中，可复制页面链接分享当前视图。
- “全部／域名／IP／其他”按规则类型筛选；列表还可按名称、最近更新或规则数量排序。每页显示 8 项，可翻页浏览。

## 自定义规则筛选

打开规则详情查看类型标签、规则格式和可用文件。对支持自定义筛选的条目，在“自定义规则”中勾选规则类型；也可全选或清空。排除规则值为可选的单条通配模式，最长 256 个字符：`*` 匹配任意字符，`?` 匹配单个字符，例如 `*.google.com`；匹配不区分大小写。

页面会按所选客户端生成兼容结果：若显示“现成文件”，直接使用该文件链接；若显示“本地过滤”，首次使用前按页面入口安装对应模块，并在客户端启用其所需的 `yanyu.rule` HTTPS 解密。页面提供“IP / ASN 规则不附加 `no-resolve`”选项时，勾选后会移除受支持 IP-CIDR、IP-CIDR6 或 IP-ASN 规则末尾的 `no-resolve`；具体适用类型随客户端而异。

本地过滤源文件上限为 1 MiB；超限或筛选后无匹配规则时，请使用详情提供的现成文件。最终订阅地址可复制后按客户端自身支持的方式添加；客户端语法和设置入口以对应版本说明为准。
